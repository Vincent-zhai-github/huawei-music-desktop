## 本 fork 新增与修改的内容

以下改动由 AI 编程助手编写实现（本人提需求、定方案、做本机验收），均已通过 typecheck、205 项离线单测（`npm test`）、`test:electron` smoke、`test:electron-ui` 与 `test:electron-business` 回归（Windows 本机）；逐轮证据见 [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md)，按提交对照的变更清单见 [docs/CHANGELOG.md](docs/CHANGELOG.md)。

### 1. 品牌与外观

- **应用名称**改为「华为音乐」（原「华为音乐第三方客户端（学习版）」）：窗口标题、任务栏、托盘提示、安装目录内 exe 名统一（`src/shared/app-name.mjs`、`package.json` productName、`src/renderer/index.html`）。`package.json` 的 `name` 字段保持不变，避免挪动 userData 路径丢失旧数据。
- **应用/托盘图标**替换为自定义设计（白底圆角方形 + 洋红/青/蓝三层叠加椭圆 + 白色音符）。图标由 `scripts/make-icon-sharp.mjs` 用 sharp 渲染 SVG 生成；音符 glyph 来自 Lucide（ISC），归属声明保留在 `build/icon.LICENSE.txt`。图标图片为手动调整版。

### 2. 无版权歌曲（新增）

- 读取接口 `status` 字段判定可用性：明确非 `"1"` 视为无版权；字段缺失视为可用（部分接口不返回该字段，避免误杀）。
- 无版权歌曲在列表中**灰色显示 + 标题删除线 + 播放按钮禁用**（禁止图标）。
- 双击、回车、点击播放按钮均无法播放；「播放全部」会**自动把队列过滤为可播放曲目**，全部无版权时给出提示。

### 3. 全局快捷键（新增，可自定义）

- 默认键位参考常见音乐播放器的 Ctrl+Alt+ 方案：播放/暂停 `Ctrl+Alt+P`、上一首/下一首 `Ctrl+Alt+←/→`、音量增减 `Ctrl+Alt+↑/↓`、静音 `Ctrl+Alt+M`、收藏当前歌曲 `Ctrl+Alt+L`。
- **全局生效**（应用未聚焦/在托盘时也可控制）；键盘物理媒体键始终有效，不受设置影响。
- 设置 → 快捷键：点击键位即可**录制新组合**（强制要求 Ctrl/Alt/Win 修饰键，避免抢占打字键；Esc 取消、Backspace 清除禁用），一键恢复默认；同组合键只绑一个动作，冲突自动消解；被其他软件占用的键位注册时静默跳过。
- 快捷键存入设置并经主进程 `sanitizeShortcuts` 落盘校验（accelerator 白名单格式 + 冲突规则），纯逻辑在 `src/shared/shortcuts.mjs`。

### 4. 桌面歌词悬浮窗（新增）

- 置顶悬浮歌词条：当前行大字 + 下一行/翻译预览，不占任务栏、全工作区可见；半透明深色胶囊背景。
- **可拖动**（解锁状态下整条拖动），位置自动记忆，重启恢复。
- **锁定后鼠标完全穿透**（不影响打字与下面窗口的操作）；悬浮条上提供锁定/关闭按钮，也可在设置页开关。
- **可设置字体颜色**（5 个预设色 + 取色器自定义，HEX 白名单校验）与**歌词背景透明度**（0–100% 滑杆实时生效；解锁态自动提亮保证控制条可读）。
- 歌词行变化时才推送（行索引去重），payload 在主进程净化（长度钳制）；歌词窗口使用独立最小 preload（无凭据、无音乐、无设置接口），安全配置与主窗口同级（sandbox、contextIsolation）。

### 5. 下一首播放（新增）

- 每行曲目新增「下一首播放」按钮（⏭）：不打断当前播放，歌曲插到当前曲之后；已在队列中的歌为**移动**而非重复添加。
- 顺序播放与随机播放模式均正确（播放顺序与队列物理顺序同步维护，正在播放的曲目始终不位移）；连续设置多首时后点的排更前；没有播放时排到队首。队列自动持久化，重启保留。

### 6. Windows 发行与本机验证

- Windows **NSIS 安装包**在 Windows 11 本机完成：原生构建 → 静默安装（per-user，自定义目录）→ 安装版启动（4 进程 + 主窗口）验证；注册表卸载项与开始菜单快捷方式就位。
- `test:electron` smoke 与 `test:electron-ui` 在 Windows 本机跑通全绿（原项目仅 Linux 验证）。
- 未签名构建；安装版登录/播放全流程与 CI Windows runner 实跑仍未验收，以 [docs/IMPLEMENTATION_STATUS.md](docs/IMPLEMENTATION_STATUS.md) 为准。

### 7. 按曲音质档位切换（新增）

- 播放坞音质按钮改为**弹出菜单**：标准 / HQ / 无损三档，当前档打勾；每首歌只显示接口返回的可用档位。
- 切换档位**立即换流并保留播放进度**，无需重播当前曲。
- 请求的档位对当前歌曲不可用时**自动回退到最接近的可用档**（优先向低找最高，否则向高找最低），并提示实际播放档位。
- 设置 → 播放 → 默认音质；队列持久化保留每曲档位，重启恢复。
- **超清（超高清音频 2.0）不提供**：实测超钻会员（最高等级）请求仍被服务端拒绝——该音质需要 HarmonyOS NEXT 设备与华为耳机 L2HC 全链路，属设备端处理流，桌面端无法使用；与会员等级无关。
- 本机实测（超钻会员）：标准 / HQ / 无损三档播放均正常。

### 8. 搜索页播放全部（新增）

- 搜索结果支持一键「播放全部」；结果分页未加载完时按钮显示「播放已加载 N 首」，只播已加载曲目，不宣称覆盖全量结果。
- 自动过滤无版权歌曲（与播放队列规则一致）。

### 9. 会话过期感知（改进）

- 华为音乐会话约 7 天过期。过期后收藏/歌单/播放等操作给出明确提示「音乐登录已过期，请重新扫码登录」，侧栏状态点亮橙显示过期状态（此前是笼统的「请求失败」提示，易误导）。
- 过期时收藏与歌单自动回退**本地缓存**，页面不再空白；重新扫码后恢复在线数据。
- 登录时开始把 OAuth refresh_token 加密留存于本机：经实测公开客户端（无应用密钥）的刷新接口已被服务端拒绝，自动续期暂不可行；留存凭据用于后续真实验证，不宣称已支持免扫码续期。
